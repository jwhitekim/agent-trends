# 검증

판단 기준은 `AGENTS.md`의 "검증 기준" 절이 원본이다.

1. 기사 목록의 매칭 근거를 보고 기사·기업 조합별로 검증한다. 대표 제목 하나로 기업 전체를 제외하지 않는다. 제외 기록과 재집계 방법은 AGENTS.md를 따른다.
2. 그룹사를 묶는다.
3. 숫자마다 기간을 붙인다(뉴스는 결과의 period 열을 읽는다).
4. 출처 링크가 결과에 실제로 있는지 확인한다.
